# 画面の使い方

| 画面 | URL |
|---|---|
| コマンドセンター | `OBS_PUBLIC_URL` (既定 http://127.0.0.1:8080/) |
| Wallboard (Grafana、動かしたときだけ) | `<OBS_PUBLIC_URL>/grafana/d/yamaha-wallboard?kiosk` |
| Grafana (動かしたときだけ) | `<OBS_PUBLIC_URL>/grafana/` |

Grafana は既定では動きません。コマンドセンターだけで、長い期間の推移とログの検索まで行えます。Grafana を使うときの手順は [operations.md](operations.md) にあります。

地球儀・地図の背景・フォントはインターネットから取得します。オフラインでは地球儀と地図の背景が表示されませんが、ほかのパネルは動きます。

## Wallboard

Grafana を動かしたときに使える、1 画面のダッシュボードで、1920×1080 の kiosk 表示に収まります。
WAN の速度、オンラインの機器の数、発報中のアラート、syslog の件数、データの鮮度、宛先の地図、機器の状態、最新の syslog を表示します。
値が取れないときの表示は、0 ではなく `NO DATA` か `STALE` です。

## コマンドセンター

中央の地球儀に、ホームから各宛先への通信をアークで描きます (橙が outbound、水色が inbound、太さが bps)。
左に機器の状態と国別の上位の宛先、右に WAN の速度とアラート、下に syslog を表示します。
地図上の位置は GeoIP による推定で、物理的な経路ではありません。
prod で `capture` profile を使わないときは、通信先のパネルに「no flow source configured」と出ます。WIRELESS CLIENTS の値は prod では不明です。

- 上部バーの鮮度バッジは `LIVE` / `DEGRADED` / `STALE` を示します。マウスを載せると、最終の更新時刻と失敗している取得元が出ます。
- アラートが発報中だと、赤い枠と `ALERT` バナーが出ます。バナーを押すと発報中のアラートの一覧が開きます。
- パネルの見出しを押すと、省略のない一覧が開きます。行を押すと、右に詳細が開きます。
- パネルを開いたり地球儀を動かしたりすると調査モードになります。`Esc` か「✕ BACK TO LIVE」で戻ります。5 分間操作がないときも戻ります。
- 地球儀はホイールかピンチで拡大し、ドラッグで回します。右上の ⟲ で初期の表示に戻ります。
- ⋯ メニューで、テーマ (STD / FILM)、描画モード、履歴再生、ログアウトを選べます。`?theme=film` でも FILM のテーマを開けます。
- 画面はタブレット (768〜1279 px) とスマートフォン (768 px 未満) にも合わせて配置が変わります。
- キーボードでは Tab で移動、Enter で開く、Esc で閉じる操作ができます。

## 推移

WAN と接続口のパネルの見出しにある `推移` で開きます。機器・IF・通信先の詳細の「推移を見る」からも、その対象に絞って開けます。

- 指標は、IF の通信量・エラー・破棄、機器の UP と稼働時間、WAN の利用率、国・ASN・LAN の端末ごとの通信量、無線の端末数、パケット取込の量とリングの使用率から選びます。
- 期間は 1h / 6h / 24h / 7d / 30d か、開始と終了の指定で選びます。グラフをドラッグすると、その区間に拡大します。「拡大を戻す」で前の期間に戻ります。
- 刻みは期間に合わせて決まり、1 系列は 600 点までです。通信先ごとの量は積み上げで描き、上位 8 件のほかは「その他」にまとめます。
- 凡例のボタンで系列を隠したり出したりできます。グラフを選んで ← → を押すと、その時刻の値を読めます。
- 値のない区間は線が途切れます (0 ではありません)。期間のすべてに値がないときは「—」と出ます。
- 履歴再生中は、期間の終わりが再生位置になります。

問い合わせはサーバー側の決まった型だけで組み立てます。画面から PromQL を送ることはありません。

## ログ検索

記録 (SYSLOG FEED) のパネルの見出しにある `検索` で開きます。機器・IF・syslog の行の詳細の「ログを検索」からも開けます。

- 機器、重要度、facility (syslog から取れたもの)、語句で絞ります。語句は大文字と小文字を区別しない部分一致です。
- 「正規表現」に印を付けると、語句を正規表現として扱います。64 文字までで、繰り返しの入れ子、先読み・後読み、後方参照は使えません。長さの決まらない繰り返し (`*` `+` `{m,n}`) は 1 か所までです。
- 期間は 15m から 30d まで (syslog の保存期間まで) です。
- 結果は新しい順に 100 行ずつ出て、一致した部分に印が付きます。「さらに古い行を読む」で続きを読みます。
- 期間の件数を時間ごとの棒グラフで示します。棒を選ぶと、その時間に絞って検索し直します。
- 行を選ぶと、その行の詳細、その時刻の原因候補、前後 10 分の証跡の出力へ進めます。

語句は伏せ字にした後の行と照らし合わせます。そのため、伏せた部分 (例 `192.168.100.x` の `x`) を語句で探ることはできません。

## 履歴再生

⋯ メニューの「履歴再生 (PLAYBACK)」を選ぶと、上部バーの下に再生バーが出ます。
期間は直近 1h / 6h / 24h / 7d から選ぶか、開始と終了の時刻を指定します。保存期間より前の時刻は選べません。
時間スライダ、再生と一時停止、コマ送り (15 秒)、速度 (0.5〜8×) を使え、「● LIVE に戻る」で通常の表示に戻ります。
再生中は画面全体がその時刻のデータになります。通知の状態は表示されず、抑止や ACK の操作はできません。

## 証跡の出力

詳細の「証跡を出力」か、再生バーの「証跡を出力」で zip をダウンロードします。
zip には期間のメトリクス (CSV)、アラートの履歴、通知の記録、syslog、任意で pcap の統計が入り、内容とハッシュの一覧が `manifest.json` に記録されます。
中身はすべて伏せ字です。生の pcap は入りません。

- 期間は再生中ならその期間、ライブなら直近 1 時間で、最長 7 日です。
- 「画面の画像」に印を付けると、押した時点の画面が `snapshot.png` として入ります。これは operator と admin だけが使えます。
- 大きさの上限は `EVIDENCE_MAX_ROWS` `EVIDENCE_MAX_LINES` `EVIDENCE_MAX_MB` などで変えられます。超えた分は切り詰められ、manifest に記録されます。

## ネットワーク図

地球儀の右上の `ネットワーク図` ボタンで、地球儀とネットワーク図を切り替えます。
図は機器台帳の `parent` / `parent_if` / `uplink_if` から作り ([configuration.md](configuration.md))、`wan_interface` を書いた機器の先には「インターネット」を描きます。
LLDP で取れた隣接は破線で描き、線ごとに出所 (`台帳` / `LLDP` / `台帳+LLDP`) を表示します。
線の色は、利用率が 70 % 以上かエラーがあると黄、90 % 以上か link DOWN で赤です。ノードや線を押すと、その機器やインターフェースの詳細が開きます。

## 急増と原因候補

端末と通信先の組で、直近 5 分の通信量が `SURGE_MIN_KBPS` (既定 200 kbps) 以上で、平常 (`SURGE_BASELINE` の中央値、既定 1h) の `SURGE_FACTOR` 倍 (既定 3) を超えたものを急増として扱います。
GLOBAL TRAFFIC と NETWORK MAP の見出しにある `急増 N` を押すと一覧が開きます。

原因候補は警報の詳細の「原因候補」、急増の一覧の行、再生バーの `原因候補` から開きます。
基準の時刻の前後 (±5 / ±10 / ±30 分) に起きた、警報、機器と IF の DOWN / UP、エラーの増加、急増、syslog、通知を、関連の深い順に並べます。
これは相関の候補で、原因を断定するものではありません。
