# 画面の操作方法

| 画面 | URL |
|---|---|
| コマンドセンター | `OBS_PUBLIC_URL` (既定 http://127.0.0.1:8080/) |

地球儀・地図の背景・フォントはインターネットから取得します。オフラインでは地球儀と地図の背景は非表示ですが、その他のパネルは動作します。

## コマンドセンター

中央の地球儀に、ホームから各送信先への通信をアークで描画します (橙が outbound、水色が inbound、太さが bps)。
左に機器の状態と国別の上位送信先、右に WAN の速度とアラート、下に syslog を表示します。
地図上の位置は GeoIP による推定であり、物理的な経路ではありません。
prod で `capture` profile の未使用時は、通信先のパネルに「no flow source configured」を表示します。WIRELESS CLIENTS の数値は prod では不明です。

- 上部バーの鮮度バッジは `LIVE` / `DEGRADED` / `STALE` を表示します。マウスオーバーで、最終更新時刻と取得失敗中の取得元を表示します。
- アラートの発報中は、赤枠と `ALERT` バナーを表示します。バナーの押下で発報中のアラートの一覧を表示します。
- パネルの見出しの押下で、省略なしの一覧を表示します。行の押下で、右に詳細を表示します。
- パネルの展開や地球儀の操作で調査モードに移行します。`Esc` か「✕ BACK TO LIVE」で復帰します。5 分間の無操作時も復帰します。
- 地球儀はホイールかピンチで拡大し、ドラッグで回転します。右上の ⟲ で初期表示に復帰します。
- ⋯ メニューで、テーマ (STD / FILM)、描画モード、履歴再生、ログアウトを選択可能です。`?theme=film` でも FILM のテーマで表示可能です。
- 画面はタブレット (768〜1279 px) とスマートフォン (768 px 未満) にも対応して配置が変化します。
- キーボードでは Tab で移動、Enter で展開、Esc で閉鎖の操作が可能です。

## 推移

WAN と接続口のパネル見出しにある `推移` で表示します。機器・IF・通信先の詳細の「推移を表示」からも、当該対象に限定して表示可能です。

- 指標は、IF の通信量・エラー・破棄、機器の UP と稼働時間、WAN の利用率、国・ASN・LAN の端末単位の通信量、無線の端末数、パケットキャプチャの量とリングの使用率から選択します。
- 期間は 1h / 6h / 24h / 7d / 30d、または開始・終了の指定で選択します。グラフのドラッグで当該区間を拡大表示します。「拡大解除」で直前の期間に復帰します。
- 間隔は期間に応じて決定し、1 系列は最大 600 点です。通信先単位の量は積上げで描画し、上位 8 件以外は「その他」に集約します。
- 凡例のボタンで系列の表示・非表示を切替可能です。グラフの選択後に ← → の押下で、該当時刻の数値を参照可能です。
- 数値のない区間は線が途切れます (0 ではありません)。期間の全域で数値がない場合は「—」を表示します。
- 履歴再生中は、期間の終端が再生位置になります。

問合せはサーバー側の規定の型のみで組立てます。画面から PromQL を送信することはありません。

## ログ検索

記録 (SYSLOG FEED) のパネルの見出しにある `検索` で表示します。機器・IF・syslog の行の詳細の「ログを検索」からも表示可能です。

- 機器、重要度、facility (syslog から取得済みのもの)、語句で絞込みます。語句は大文字・小文字を区別しない部分一致です。
- 「正規表現」の選択で、語句を正規表現として処理します。最大 64 文字で、繰返しの入れ子、先読み・後読み、後方参照は使用不可です。長さ不定の繰返し (`*` `+` `{m,n}`) は 1 か所までです。`?` は、長さ不定の繰返しとの併用時は 1 か所、単独時は 4 か所まで使用可能です。
- 期間は 15m から 30d まで (syslog の保存期間まで) です。
- 結果は最新順に 100 行単位で表示し、一致部分にマークを付与します。「過去行の追加読込」で続きを読込します。
- 期間内の件数を時間単位の棒グラフで表示します。棒の選択で、該当時間に限定して再検索します。
- 行の選択で、該当行の詳細、該当時刻の原因候補、前後 10 分の証跡の出力に移行可能です。

語句はマスク処理後の行と照合します。そのため、マスク部分 (例 `192.168.100.x` の `x`) を語句で探索することは不可能です。

## 履歴再生

⋯ メニューの「履歴再生 (PLAYBACK)」の選択で、上部バーの下に再生バーを表示します。
期間は直近 1h / 6h / 24h / 7d からの選択か、開始と終了の時刻の指定です。保存期間より前の時刻は選択不可です。
時間スライダ、再生と一時停止、1 ステップ前進 (15 秒)、速度 (0.5〜8×) を利用可能で、「● LIVE へ復帰」で通常表示に復帰します。
再生中は画面全体が該当時刻のデータになります。通知の状態は非表示で、抑止や ACK の操作は不可です。

## 証跡の出力

詳細の「証跡を出力」か、再生バーの「証跡を出力」で zip をダウンロードします。
zip には期間内のメトリクス (CSV)、アラートの履歴、通知の記録、syslog、任意で pcap の統計を格納し、内容とハッシュの一覧を `manifest.json` に記録します。
内容は全件マスク済みです。生の pcap は含みません。

- 期間は再生中であれば該当期間、ライブであれば直近 1 時間で、最長 7 日です。
- 「画面の画像」の選択で、押下時点の画面を `snapshot.png` として格納します。本機能は operator と admin のみ利用可能です。
- 容量の上限は `EVIDENCE_MAX_ROWS` `EVIDENCE_MAX_LINES` `EVIDENCE_MAX_MB` などで変更可能です。超過分は切捨てし、manifest に記録します。

## ネットワーク図

地球儀の右上の `ネットワーク図` ボタンで、地球儀とネットワーク図を切替えます。
図は機器台帳の `parent` / `parent_if` / `uplink_if` から生成し ([configuration.md](configuration.md))、`wan_interface` を記載した機器の先には「インターネット」を描画します。
LLDP で取得した隣接は破線で描画し、線単位で出所 (`台帳` / `LLDP` / `台帳+LLDP`) を表示します。
線の色は、利用率が 70 % 以上かエラー発生時は黄、90 % 以上か link DOWN 時は赤です。ノードや線の押下で、該当機器やインターフェースの詳細を表示します。

## 急増と原因候補

端末と通信先の組で、直近 5 分の通信量が `SURGE_MIN_KBPS` (既定 200 kbps) 以上、かつ平常値 (`SURGE_BASELINE` の中央値、既定 1h) の `SURGE_FACTOR` 倍 (既定 3) を超過したものを急増として処理します。
GLOBAL TRAFFIC と NETWORK MAP の見出しにある `急増 N` の押下で一覧を表示します。

原因候補は警報の詳細の「原因候補」、急増の一覧の行、再生バーの `原因候補` から表示します。
基準時刻の前後 (±5 / ±10 / ±30 分) に発生した、警報、機器と IF の DOWN / UP、エラーの増加、急増、syslog、通知を、関連度の高い順に表示します。
本機能は相関の候補であり、原因の断定ではありません。
