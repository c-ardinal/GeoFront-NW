# P4 仕様: 履歴再生と証跡出力

親計画: `docs/plans/v2/PLAN.md`（承認済み。P3 は b98a7cd で完了）

## 受入条件
1. **PLAYBACK モード**（仕様 04 章・10 章の状態機械）: 上部バーの設定メニュー（⋯）または時間帯の選択から「履歴再生」に入る。
   - 開始・終了時刻の指定（直近 1h/6h/24h/7d のプリセット＋任意入力）、時間スライダ、再生速度 0.5/1/2/4/8×、一時停止・コマ送り（1 ステップ）
   - 画面全体（全パネル・地球儀・アラート一覧・syslog・詳細・モーダル）が「その時刻時点」のデータを表示する（Prometheus の時刻指定クエリ、Loki の時間窓）。地球儀のアークもその時刻のフローで描く
   - 再生中は「履歴再生 HH:MM:SS」の固定バナー（幅固定）を出し、鮮度バッジは LIVE ではなく PLAYBACK を表示。自動更新（ライブのポーリング）は止める
   - 「LIVE に戻る」で WALLBOARD・直近 15 分・自動更新に戻る。5 分無操作で自動復帰はしない（再生中は除外）
   - データが無い時刻は「—」（0 にしない）。保持期間外は理由付きで無効
2. **証跡出力**（FR-020）: アラート（ドロワー）または選択した期間から「証跡を出力」で zip をダウンロード:
   - 期間・フィルタ・対象（機器/IF/通信先/アラート）・データソースと版（Prometheus/Loki/Grafana/本ツールのコミット）・出力日時・出力者（今は local）
   - その期間の関連メトリクス（CSV）、関連ログ（伏せ字済みテキスト）、アラート履歴（ALERTS と通知記録）、可能なら関連パケットの統計（P3 の統計 JSON。生 pcap は含めない）
   - 画面のスナップショット（任意、ブラウザ内で生成した PNG）
   - すべて伏せ字済み。ファイル名・メタデータにもアドレスを入れない
   - サイズ上限と行数上限（超過時は manifest に「切り詰め」と記録）
3. **API**: 出力はサーバ側で組み立てる（mask-api の読み取り経路を通し、伏せ字を保証）。読み取りのみ。重い処理は同時 1 件・タイムアウト付き
4. **画面規則**: 既存の規則（重複なし・幅固定・STALE と —・44px・キーボード・両テーマ・全画面サイズ）

## 不変条件
- 伏せ字と書き込み制限（P1〜P3）を維持。証跡出力に生アドレス・生 pcap を含めない
- ライブ表示の挙動は変えない（PLAYBACK に入らない限り）

## 検証の制約（オーナー指示）
- コンテナは確認時のみ起動・終了後停止、ブラウザは同時 1 つ（browser.lock）
